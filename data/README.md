# Data Sources

Synthetic source-style data for banking agentic AI workflow transformation, human-in-the-loop controls, backlog refinement, and financial-services adoption governance.

- `entities.csv`: 36 banking workflow records.
- `daily_metrics.csv`: 5,040 banking workflow-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
